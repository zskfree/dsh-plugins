# Lambda额度管理

只在 DSH 独立面板展示现有看板，不重写网页；可在本机记住看板密码并自动调用原站登录接口。

- 固定地址：`http://47.115.165.231:30179/`，无 HTTPS 或备用切换。
- 桌面程序使用 DSH 原生安全网页载体；普通浏览器提供独立打开入口，避免跨站 iframe 的 Cookie 限制。
- HTTP 未加密，密码和会话有明文传输风险。
- 桌面插件首次使用时，在面板顶部输入密码并点“记住并登录”；此后重新打开或重启 DSH，在登录页出现时自动登录。不需要把密码交给 Agent 或写进源码。
- 密码保存在 DSH 当前桌面配置的 localStorage（键 `dsh-lambda-dashboard.password.v1`），是本机明文配置，不在插件源码、Git、URL 或日志中。清除 DSH 网页存储、切换配置或迁移机器后需重新设置。
- 当前 DSH 网页载体使用内存会话，退出 DSH 后 Cookie 不保留；插件通过已保存密码在下次打开时重新登录。原站会话过期导致页面返回登录页时也会尝试登录。密码错误或网络异常会停止当前尝试并提示，可修改密码或“重新加载”。
- “忘记密码”只删除本机保存的密码，不撤销已存在的远端会话；需要退出时使用原页面的退出登录。普通浏览器的“独立打开”不注入密码。
- 不保证远端服务、网络或账号一直可用，不修改服务端认证或会话有效期。
- 不启动 SSH、Python 子进程、本地监听或代理，不修改远端服务。登录后的操作直接作用于原服务。

## 安装

适用 DSH `0.2.2-rc.1`。以 `link:D:/DEV/projects/dsh-plugins/dsh-lambda-dashboard` 安装并启用；无需构建或 Python 依赖。修改客户端后需重新加载桌面窗口，必要时重启 DSH。

## 验证

`node --test tests/plugin.test.mjs` 检查入口名称、网页载体生命周期、固定地址、密码本机保存和自动登录成功/失败路径。测试仅使用合成密码。

可选：安装项目测试依赖后执行 `node tests/browser-smoke.mjs`，用 Edge 验证 React 渲染、固定 HTTP 地址与浏览器降级提示。测试不使用真实密码；桌面实际登录与页面效果由用户验收。
